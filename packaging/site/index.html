Filetrace downloads

Packages and the installer of Filetrace. The installer sets up the repository that fits the system and installs the package:

curl -fsSL https://filetrace.eorlov.org/install.sh | sudo sh

The repositories live under apt/, rpm/ and apk/, and the files of each release under dist/, in a directory named after its tag. The apt and yum metadata is signed with gpg.key; the apk repository with filetrace.rsa.pub. The README lists the manual steps for each package manager and for Homebrew.
